# Waypoint · iPhone 定位控制台

面向步道乐跑使用场景开发的 iOS 虚拟定位工具，支持 Mac 与 Windows。项目独立开发，与步道乐跑官方无关联。

USB 连接 iPhone，在电脑上搜索地名、选点、编辑并收藏地址和路线、按速度或配速播放、暂停继续、方向微调和恢复定位。界面运行在本机浏览器，程序必须保持运行。

**状态：实验版 0.4。已在连接的 iPhone 上验证定位服务连接，接口返回 iOS 27.0；坐标注入效果和步道乐跑记录仍待实测。**

## Mac 启动

1. 从 GitHub Releases 下载发行包并解压整个文件夹，双击 `start-mac.command`，或打开附带的 `Waypoint.app`。也可克隆仓库后双击 `start-mac.command`。首次启动会创建独立 Python 环境并联网安装依赖，需要 Python 3.11+，推荐 3.13。
2. 手机通过数据线连接 Mac，解锁并确认“信任此电脑”。开启“设置 → 隐私与安全性 → 开发者模式”，按提示重启。
3. 浏览器自动打开后，点“刷新”，选择 iPhone，再点“准备并连接”。首次准备可能联网下载开发者组件。
4. 切换到左上角的“单点定位”，点击地图选址，再点“应用编辑位置”。打开 iPhone 自带地图并定位到当前位置，确认蓝点是否移动。
5. 切换左上角的“路线模拟”，沿道路依次点击，选择“按配速”或“按速度”，设置圈数，再点“开始路线移动”。暂停会保持最后发送位置。
6. 结束时点击“恢复真实定位”或“恢复并退出”，并在手机地图确认恢复。

如果 macOS 阻止直接打开，可在终端进入解压目录，执行：

```sh
python3 launch.py
```

只预览界面：双击 `preview.command`，或 `python3 app.py --demo`。演示模式不会访问 iPhone。

## Windows 启动

安装 Python 3.11+ 和 Apple Devices，再解压、双击 `start-windows.bat`。连接步骤与 Mac 相同。Windows 启动脚本和 Apple 驱动连接尚未经 Windows 实机测试。

## 路线与地图

演示模式下，地图底部的“跑步动效”会让蓝点随行进方向轻微摆动。暂停会定格动效，到达终点后显示定位圆环。此开关只控制地图显示。

- 点击地图上方的“搜索”，输入地名后按回车。结果显示名称和地址，点击后移动地图；不会自动添加路径点，也不会直接改变手机位置。

- 默认使用高德电子地图瓦片，可通过地图右上角下拉框切换到 OpenStreetMap 备用源。两者都需要联网；地图失效时仍可输入坐标和导入路线。加载失败时点击“重试”重新获取瓦片。
- 高德底图使用 GCJ-02，地图显示和点击选点时会自动进行 WGS84 ↔ GCJ-02 数学换算。输入框、路线文件和发往手机的坐标始终使用 **WGS84**；切换地图源不会修改已编辑路线。
- 手动粘贴的高德 GCJ-02 和百度 BD-09 坐标仍需先转换为 WGS84。自动换算只针对地图上的显示与点击，不会猜测手动输入的坐标类型。
- 瓦片按来源分开缓存，不预先下载其他区域；加载失败有明确提示，单次请求超过 12 秒可重试。
- 默认地图在石家庄附近，仅为编辑起点，并非手机真实位置。浏览时拖动地图平移。Mac 默认双指平移、捏合缩放，使用鼠标时可将地图右上角切换到“滚轮缩放”。
- 相邻路径点按大圆弧连接，短距离近似直线；不会自动沿道路寻路。
- 路线编辑时点击空白处加点，点击节点选中，拖动节点调整位置。Delete 删除选中点。撤销用 ⌘/Ctrl+Z，重做用 ⌘/Ctrl+Shift+Z。
- 支持本工具 JSON 路线的导入导出，以及仅包含一条路线或一段轨迹的 GPX 导入。GPX 时间戳不用于回放，速度取自面板。
- 蓝色点与“已发送路线进度”表示向手机发送的坐标，不是读取回来的实测 GPS。
- 方向按钮每次移动 10 米，并停止之前的路线播放。
- 刷新或关闭网页不会结束后台模拟；应先恢复定位并退出。终端意外退出、拔线或系统强制终止时，不能保证恢复指令被送达。重新连接并恢复，必要时重启 iPhone。

## 配速与随机变速

- 默认选中“按配速”，目标为 6 分 00 秒/公里，勾选平滑随机变速，速度波动幅度为 ±12%。可调整为 ±0–30%，或关闭随机变速。
- “按速度”模式保留原有的恒定 km/h 设置。
- 随机模式使用连续的平滑变化；每次开始路线都会生成不同的变化过程。波动百分比针对速度，有限长度路线的实际平均配速可能略偏离目标值。
- 界面显示当前配速、当前 km/h 和已发送路线的平均配速。暂停期间不推进配速变化或累计移动时间。
- 开始路线会自动使用面板上的设置；播放期间修改参数后点击“应用移动设置”，可在当前位置更新设置。
- 路线导出会保留配速与随机幅度，仍兼容旧版仅保存恒定速度的路线文件。GPX 导入后使用当前面板中的移动设置。
- 随机配速仅改变坐标发送进度，不生成系统步数或运动传感器数据。

## 步行随机偏移（GPS 漂移测试）

在“路线模拟 → 移动设置”中勾选“步行随机偏移 · GPS 漂移”，设置最大偏移后开始路线。新页面默认启用，最大偏移为 **2 米**，可在 **0.5–10 米**之间调整。按速度和按配速都支持，随机变速可以独立开启或关闭。

- 发送坐标由理想路线叠加缓慢漂移与小幅摆动生成；每次开始路线随机生成变化过程。它用于合成 GPS 漂移测试，不代表真实接收器的误差分布。
- 开始时从零偏移平滑进入，播放中修改半径或开关后点击“应用移动设置”，会在接下来的 **5 秒移动时间**内过渡。调小半径或关闭时，过渡期间可能仍保留旧幅度的部分偏移，避免瞬间跳回路线。
- 暂停会冻结位置和偏移过程，继续时接着变化。调整速度不会重新生成偏移；多圈经过起点时保持连续。最后 30 米逐渐收回，终点保持原始精确坐标，所以很短的路线偏移较小。
- “已发送偏移”显示已发送位置相对当前理想路线点的距离。路线里程、进度、配速仍按原路线计算，接收端根据偏移坐标计算的里程或速度可能不同。
- JSON 导入导出、路线收藏及撤销载入保留偏移设置。旧文件和旧收藏没有偏移字段时默认关闭，GPX 沿用当前面板设置。
- 此功能作用于设备适配器收到的 WGS84 坐标；“跑步动效”仍只控制地图动画。单点定位、10 米微调和恢复定位不叠加随机偏移。

## 收藏地址与路线

- 在地图上选点、搜索定位或输入有效 WGS84 坐标后，点“收藏地址”，填写名称并保存。地址保留坐标和地图缩放级别，不依赖搜索服务是否收录该地点。
- 画好路线并调整移动设置后，点“收藏路线”。保存全部路径点、闭合状态、圈数、速度/配速模式、随机变速开关、波动幅度、随机偏移开关和最大偏移。
- 下次启动点地图上方的“收藏夹”，切换地址/路线并按名称筛选。“定位地图”保留现有路线；“载入路线”恢复该路线及其设置。载入只改变编辑内容，点击开始后才会发送路线。
- 可点击“撤销载入”恢复上一次载入前的编辑内容。改名和移入回收站也在收藏夹中完成；误删后勾选“回收站”再点“恢复”。同类型重名会提示，不会覆盖已有收藏。
- 收藏保存在电脑上的 SQLite 文件，关闭网页、重启程序或更换本机服务端口后仍保留。源码/便携启动默认使用项目内 `user-data` 目录；更新时请保留此目录。Mac `.app` 默认使用 `~/Library/Application Support/Waypoint`，更新应用包不会覆盖收藏。
- 可通过 `WAYPOINT_DATA_DIR` 或 `--data-dir` 指定其他数据目录。演示模式默认使用独立的 `user-data-demo`。发行压缩包不包含任何用户收藏数据；JSON 路线导出仍可用于单条路线备份。

## 地名搜索服务

默认使用无需 Key 的 Nominatim / OpenStreetMap 搜索，高德底图继续照常使用。该搜索对国内小地名的收录有限，可尝试“城市 + 地名”，或在地图选点后收藏。只在明确点击搜索或按回车时发送地名；请求有缓存和频率限制。搜索在独立 HTTP 工作线程运行，不阻塞轨迹播放。

如需使用高德国内 POI 搜索，可在启动前设置 `WAYPOINT_AMAP_KEY` 为自己的**高德 Web 服务 Key**，程序会自动改用高德搜索。Key 只用于后端请求，不返回给浏览器，也不写入操作日志。高德返回的 GCJ-02 结果会转换为 WGS84 后作为选中位置。

`WAYPOINT_SEARCH_PROVIDER` 可设为 `auto`、`amap` 或 `nominatim`；`WAYPOINT_NOMINATIM_URL` 可配置其他 HTTPS Nominatim 服务。修改后重启生效。未配置高德 Key 时可直接使用默认搜索；实际速度和覆盖范围取决于服务及网络，失败后可点击搜索重试。

## 连接失败

- 检查手机解锁、数据线可传数据、信任提示、开发者模式。
- Mac 可勾选“Mac 原生连接方式”重试。这一方式可能与 Xcode 的设备连接互相干扰；默认使用跨平台的用户态隧道。
- 首次开发者组件准备需要访问 Apple 下载服务。网络失败时保留原始错误日志，不会将进程启动当作定位成功。
- 设备中途断开后，程序停止推进路线并显示错误；插回原手机，点击“重新连接”，程序会先尝试恢复之前的模拟状态。
- iOS 更新可能改变协议。若工具返回成功但手机地图没变，兼容性仍未通过；不能据此判定应用已经获得模拟位置。

## 实现与验证范围

- Python 标准库提供本机 HTTP 界面；只监听 `127.0.0.1`，每次运行使用新的会话令牌，校验 Host 与 Origin。设备标识不会写入持久日志。
- `pymobiledevice3==11.50.2` 提供 USB 识别、开发者组件准备、`PreferredRsdTunnel`、`DvtProvider` 和 `LocationSimulation`。连接与定位保持在同一进程、同一异步会话。
- 位置发送失败或恢复失败会保留待恢复状态。更换另一台设备前必须先恢复原设备。
- 不读取步道乐跑账号，不调用其私有接口，不修改系统步数，不包含针对该应用的检测规避功能。
- 自动测试使用明确的假设备适配器，覆盖路线时间、暂停与继续、坐标边界、发送失败、恢复失败与断线重连。测试通过不代表 iOS 实机兼容。

```sh
python3 -m unittest discover -s tests -v
node --test tests/test_map_coordinates.mjs tests/test_motion_ui.mjs
```
